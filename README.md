# Indicadores de mortalidade — ES

Dashboard acadêmico de Daniel Breda Bigossi (Engenharia de Produção, UFES).

Execute `pip install -r requirements.txt` e `streamlit run app.py`. Python 3.12.

Dados em `dados/dataset.zip`. Meses ainda não disponíveis são bloqueados no painel. A população-fonte do ano anterior é identificada quando aplicada provisoriamente.

Para publicar no Streamlit Community Cloud, use `app.py` como arquivo principal. Confira a visibilidade e os espectadores autorizados antes de compartilhar.
